# 입시나침반 (admission/)

내신·모의고사·수능 가채점 점수로 지원 가능한 대학·학과를 추천하고, 과거 입결(컷)을 조회하는 정적 사이트입니다.
빌드 없이 GitHub Pages에서 바로 동작합니다: `https://seoulcoin-ceo.github.io/helpdesk/admission/`

## 구성
| 파일 | 역할 |
|---|---|
| `index.html` | 화면 (홈 / 내신 계산 / 모의고사·수능 / 대학 추천 / 입결 조회 / 입시 가이드) |
| `style.css` | 디자인 (라이트·다크 모드, 모바일 대응) |
| `app.js` | 계산·추천·조회 로직. 입력 성적은 브라우저 localStorage에만 저장 |
| `data/admission-data.js` | 입결 데이터 |

## ⚠️ 현재 데이터는 샘플입니다
`data/admission-data.js`의 수치는 기능 시연용 **가짜 데이터**입니다. 실제 서비스 전에
대학어디가(adiga.kr) 대학별 입결, 각 대학 입학처 발표 자료로 교체하세요.
교체 후 `isSample: false`로 바꾸면 상단 경고 배너가 사라집니다.

## 데이터 형식 (records 한 줄 = 대학·학과·연도 1건)
| 필드 | 의미 | 예 |
|---|---|---|
| `year` | 입시년도(학년도) | `2026` |
| `univ`, `region`, `major` | 대학, 지역, 모집단위 | `"부산대"`, `"부산"`, `"경영학과"` |
| `field` | 계열 `인문` / `자연` | `"인문"` |
| `susiType` | 수시 전형명 | `"학생부교과"` |
| `susiQuota`, `susiRate` | 수시 모집인원, 경쟁률 | `12`, `8.4` |
| `susiCut50`, `susiCut70` | 교과 50%/70% 컷 (9등급 기준) | `2.21`, `2.38` |
| `susiFinal` | 최종 등록자 최저 | `2.60` |
| `jungsiGun`, `jungsiQuota`, `jungsiRate` | 정시 군, 모집인원, 경쟁률 | `"가"`, `20`, `4.5` |
| `jungsiCut50`, `jungsiCut70` | 정시 국수탐 평균 백분위 50%/70% 컷 | `91.2`, `90.6` |

값이 없는 항목은 `null`로 두면 해당 추천·차트에서 자동 제외됩니다.
엑셀로 관리한다면 위 열 이름으로 시트를 만들고 JSON으로 변환해 `records` 배열에 붙여 넣으면 됩니다.

## 추천 기준
- 비교 컷 = 최근 3개년 70%컷 가중평균 (최근 50%, 전년 30%, 전전년 20%)
- 수시 교과: 70%컷 − 내 등급 ≥ +0.3 안정 / ≥ 0 적정 / ≥ −0.3 소신 / ≥ −0.7 상향
- 정시: 내 환산 백분위 − 70%컷 ≥ +1.5 안정 / ≥ 0 적정 / ≥ −1.5 소신 / ≥ −3 상향
- 정시 환산: 인문 국40·수30·탐30, 자연 국30·수40·탐30 (백분위), 영어 등급·한국사 5등급 이하 감점
- 5등급제 내신은 누적비율 기준으로 9등급 근사 환산 후 비교

기준값은 `app.js`의 `classify`, `WEIGHTS`, `ENG_PENALTY`에서 조정할 수 있습니다.
